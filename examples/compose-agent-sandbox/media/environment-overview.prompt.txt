Use case: infographic-diagram
Asset type: editorial illustration for the WorkSpaces Compose sandbox feature guide.
Primary request: communicate that a small, self-contained directory defines an entire Linux working environment, and that a person can enter that environment through the crafted native WorkSpaces terminal app or directly through a terminal.
Scene and composition: a wide, precisely composed technical cutaway illustration on warm ivory paper. On the left, a compact open folder with three visible file cards labeled exactly "compose.yaml", "Dockerfile", "smoke.sh". The folder is physically separate from the environment, connected by one fine arrow labeled "defines". In the center, the main subject is one elegant isometric open enclosure labeled "Workspace environment". Inside it are a sage green Linux terminal module, a distinct working-copy drawer, a home-volume drawer, and a small optional database cylinder. These four parts are clearly arranged within one common boundary, not separate unrelated computers. On the right, two separate, simple entry windows connect with thin lines to the SAME central terminal module: the top is a restrained native desktop window with a sidebar and terminal, labeled "WorkSpaces"; below is a direct shell window labeled "Terminal". These windows are explanatory representations, not purported screenshots of a real app.
Exact labels inside the environment: "Linux terminal", "Working copy", "Agent home", "Database (optional)". Use no other labels or paragraphs. File cards have only their stated filenames. Text is crisp, sparse, carefully typeset, legible at normal website width. No title or headline, the surrounding HTML supplies it.
Style: sophisticated architectural model meets a technical field guide. Fine charcoal outlines, subtle paper grain, restrained tactile depth, flat surfaces with soft precise shadows, mostly orthographic/isometric geometry. Warm off-white #f5f3ec background, forest green #265d3c and pale sage #e7eee2 accents, charcoal #242b27 type. Not a glossy SaaS infographic. Generous whitespace between the three groups. Composition remains readable at half size.
Conceptual constraints: source configuration is outside the running environment; working copy is only one part of the environment; two interfaces enter one runtime, not two duplicate runtimes. No cloud, locks, shields, robots, mascots, Docker whale or invented logos. No security or isolation guarantees. No additional decorative props. Do not imply the app automatically imports arbitrary Compose directories. Both entry windows merely represent access to a workspace.
