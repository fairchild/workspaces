# Spaces Web

Next.js dashboard for the Workspaces app — GitHub OAuth sign-in, workspace management, and webhook activity feed.

## Stack

- **Next.js 15** with App Router
- **Better Auth** for GitHub OAuth
- **LibSQL / Kysely** for persistence
- **Biome** for linting
- **pnpm** package manager

## Development

```bash
pnpm install
pnpm dev
```

## Deploy

Deployed to Vercel with root directory set to `web/`.
