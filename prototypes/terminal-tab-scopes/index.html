Per-Scope Terminal Tab Collections

Each Terminal Scope — Home (~/code), a Repository's root terminal, or a Workspace — owns its own tab strip. Selecting one in the sidebar shows only that scope's tabs. The repo-root terminal is not a Workspace; it's reached from the Overview, and once it has live tabs the folder row resumes it directly. Click around — it's live.
