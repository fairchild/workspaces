Product Context

WorkSpaces is a Mac app for managing isolated AI coding sessions. Users add git repos from their Mac, fork them into independent workspaces, and run Claude Code or similar tools in an embedded terminal. Each workspace is a clean copy with automatic setup via lifecycle hooks.

STORY 1 First-Time Setup

As a developer new to WorkSpaces

I want to add my first repository and create a workspace so that I can start an isolated AI coding session

User has just installed the app and wants to set up their first workspace for a project.

Story flow images pending

Use /image-gen to generate sequential screen mockups for this flow.

Steps in this story:

  1. Launch app, see empty state
  2. Click "Add Repository", folder picker opens
  3. Select project, repo appears in sidebar
  4. Right-click repo, "New Workspace..."
  5. Enter name, workspace created
  6. Terminal opens in new workspace

STORY 2 Switching Workspaces

As a developer with multiple active workspaces

I want to quickly switch between them so that I can context-switch without losing my place

User has several workspaces and needs to move between them efficiently.

Story flow images pending

Steps: Click workspace in sidebar → Terminal switches → Right pane updates

STORY 3 Parallel Experiments

As a developer exploring different solutions

I want to create multiple workspaces from the same repo so that I can experiment without affecting other work

User is evaluating two approaches and wants isolated environments for each.

Story flow images pending

Steps: Right-click repo → Create "approach-a" → Create "approach-b" → Both visible in sidebar

STORY 4 Cleanup

As a developer who finished a task

I want to archive or delete a workspace so that I can keep my workspace list clean

User has completed work in a workspace and wants to clean up.

Story flow images pending

Steps: Right-click workspace → Delete → Confirmation dialog → Workspace removed
