# Papers

Reference papers relevant to WorkspaceManager's design.

## AWCP: A Workspace Delegation Protocol for Deep-Engagement Collaboration across Remote Agents

- **Authors**: Xiaohang Nie, Zihan Guo, Youliang Chen, Yuanjian Zhou, Weinan Zhang
- **Link**: https://arxiv.org/abs/2602.20493
- **Summary**: Introduces AWCP, a protocol enabling LLM-based autonomous agents to collaborate by sharing workspaces and directly accessing each other's files and tools, rather than relying solely on message passing. Reduces context gaps and enables more efficient cooperation across distributed agent systems.
