Features

Workspace Management

Create isolated git worktrees for each AI coding session. Keep your main branch clean while experimenting.

Integrated Terminal

Full-featured terminal emulator built-in. Run commands, view output, and manage your session in one window.

Repository Browser

Browse files and view git status at a glance. See what changed in your workspace without switching apps.

Lifecycle Hooks

Custom setup.sh and archive.sh scripts run automatically when workspaces are created or deleted.

Installation

  1. Download the DMG file using the button above
  2. Open the DMG and drag WorkSpaces to your Applications folder
  3. On first launch, right-click the app and select Open to bypass Gatekeeper
  4. Configure your workspace root directory in Settings

Note: This app requires access to your filesystem and terminal for workspace management. It's distributed outside the App Store because it needs capabilities that sandboxed apps cannot provide.
